## Overview

Horizen fuses spectral morphing oscillators with a classic subtractive filter and modulation matrix, bridging the gap between organic acoustic timbres and punchy synthetic bass and lead sounds.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Synth Factory Horizen** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Spectral Oscillators** | Partial-based oscillators that morph between up to six spectral frames |
| **Subtractive Filter** | State-variable filter with LP, HP, BP, and notch modes and drive |
| **Mod Matrix** | 32-slot modulation matrix with six LFOs and six envelopes |
| **Unison Detune** | Up to 16 detuned voices with spread, blend, and pan options |
